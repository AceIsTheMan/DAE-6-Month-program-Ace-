One shared partial so every spot stays visually/behaviorally identical and a future change (new expiry copy, new animation) only has to happen once. Usage: {% include "_vip_badge.html" with vip_user=some_user %} `vip_user` must be a CustomUser instance (or None/AnonymousUser - this silently renders nothing then, since AnonymousUser has no is_vip).
